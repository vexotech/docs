# Errors

The **Errors** page lists the JavaScript errors that happen on your website, grouped so that each bug appears once. To open it, click **Errors** in the sidebar of your web dashboard. The page is available once you set your website's domain in **App Settings**.

## What Vexo captures

The Vexo script captures two kinds of errors:

- Uncaught errors, marked **Error**.
- Unhandled promise rejections, marked **Promise**.

It doesn't capture:

- Failures to load a resource, such as an image or a script.
- `Script error.` reports. Browsers hide the details of an error in a script from another domain unless you load that script with the `crossorigin` attribute.
- Errors in the Vexo script itself.
- Errors that happen while tracking is off, for example before a visitor gives consent.

To keep a broken page from flooding your data, the script sends the same error at most 5 times, and at most 50 errors in total, for each page load. It keeps up to 1,000 characters of each message and 2,000 characters of each stack trace, and it removes query strings and fragments from the URLs in them. Each error that it sends counts as an event toward your monthly usage.

To stop capturing errors, see [Turn off errors or Core Web Vitals](/web-guide/integration#turn-off-errors-or-core-web-vitals).

## How Vexo groups errors

Errors with the same name, message, source file, and line form one group.

## Find an error

The list shows the error groups in the date range that you choose at the top of the page, most frequent first. Each row shows the error's message, **Occurrences**, **Affected sessions**, and when it was **Last seen**. Scroll down to load more groups.

The page uses only the date range filter.

## Investigate an error

Click a row to open the error's page. It shows:

- **Where it happens**: how many times the error happened on each route.
- **Recent occurrences**: up to 100 of the latest occurrences, each with its stack trace and route. Click **Watch replay** to open the session's replay.

Web errors don't have a status or an assignee.
