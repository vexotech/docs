# Quickstart

## React Native

**Prerequisites**

- Using [React Navigation](https://reactnavigation.org/) or [Expo Router](https://docs.expo.dev/router/introduction/)
- React Native 0.74 or later, on the New Architecture or the old architecture
- iOS 15.1 or later as your app's minimum deployment target

**Expo**

- ✅ You can use this library with [Development Builds](https://docs.expo.dev/development/introduction/). No config plugin is required.
- ❌ This library can't be used in the "Expo Go" app because it [requires custom native code](https://docs.expo.dev/workflow/customizing/).

**Expo SDK 58**

- Use `vexo-analytics` **1.14.0 or later** on Expo SDK 58. Earlier versions record nothing on SDK 58. See [Upgrading to Expo SDK 58](/react-native-guide/expo-sdk-58) for the support table and the upgrade checklist.
- Keep the `vexo()` call at module scope of the root layout (`app/_layout.tsx`, or `src/app/_layout.tsx` in the SDK 58 template).

### Install

1. [Create an account](https://www.vexo.co/sign-up).
2. When prompted, create an app and give it a name (you can change it later). Vexo generates the app's API key. You can copy it again later from the app's [settings](/settings/app-settings/app-general-information).
3. Install the package.

   With Expo:

   ```bash
   npx expo install vexo-analytics
   ```

   With bare React Native, install it with npm (or `yarn add vexo-analytics`), then install the iOS pods:

   ```bash
   npm install vexo-analytics
   cd ios && pod install
   ```

4. Call `vexo()` with your API key in your app's entry file: usually `index.js` or `App.js`, or the root layout (`app/_layout.tsx`) with Expo Router.

   ```javascript
   import { vexo } from 'vexo-analytics';

   vexo('YOUR_API_KEY');
   ```

   <Warning message={(<div>Call <code>vexo()</code> at module scope, outside any component or <code>useEffect</code>, so tracking starts when the app starts.</div>)} />

5. Rebuild the app, because `vexo-analytics` includes native code. A JavaScript reload or an over-the-air update isn't enough.
   - With Expo: run `npx expo run:ios` or `npx expo run:android`, or make a new development build with `eas build --profile development`.
   - With bare React Native: run `npx react-native run-ios` or `npx react-native run-android`.

### Verify your first event

1. Open the app on a device or simulator, and move between two screens.
2. Wait about 5 seconds. The SDK sends events in batches: when it has 20 events, or 5 seconds after the first one, whichever comes first.
3. Open your app in [Vexo](https://www.vexo.co/apps) and reload the page. Your device is listed under **People**, and the "Your app doesn't have data yet" banner is gone. (If you haven't verified your email address, the email verification banner shows there instead.) 🎉

**Wait, that's it?** Yes! From here, Vexo tracks sessions, screens, taps, and errors with no more code. Go [check out the features](/react-native-guide/mobile-features/overview).

### No events?

Check these, most common first:

- **Expo Go.** Expo Go can't load the SDK's native code. Use a development build (step 5).
- **A `__DEV__` guard.** If you wrapped `vexo()` in `if (!__DEV__)`, a development build never calls it. Remove the guard while you test.
- **A wrong or invalid API key.** Events sent with an invalid key are dropped. In a development build, the console shows `Vexo: API key rejected (401)`. Copy the key again from the app's [settings](/settings/app-settings/app-general-information).
- **Native code not rebuilt.** After you install or upgrade `vexo-analytics`, rebuild the app (step 5).
- **Simulator networking.** The simulator or emulator must be able to reach `https://api.vexo.co`. Check that it has network access and that a VPN, proxy, or firewall isn't blocking it.
- **Expo SDK 58.** Use `vexo-analytics` 1.14.0 or later. See [Upgrading to Expo SDK 58](/react-native-guide/expo-sdk-58).

### Before you ship

Decide whether your development sessions should count in your analytics. To leave them out, or to send them to a staging app, see [Development & staging](/react-native-guide/integration#development--staging). Before you publish, check [App Store & Play Compliance](/react-native-guide/store-compliance).

## Web

1. [Create an account](https://www.vexo.co/sign-up).
2. Create a web app:
   - On your dashboard, click **+ Add Application**.
   - Enter a name, such as your website's name.
   - Add the domain of your website, such as *example.com*.
3. Add the Vexo script. To start collecting web analytics data, paste this script into your site's `<head>` tag:

   ```html
   <script src="https://www.vexo.co/analytics.js" defer></script>
   ```

   With Next.js, use the `Script` component instead, as shown in [Next.js integration](/web-guide/integration#nextjs-integration).
4. Optional: track custom events and identify devices.

   Custom event:

   ```js
   globalThis.vexo?.customEvent('purchase-completed', { amount: 24.99 });
   ```

   Identify a device:

   ```js
   globalThis.vexo?.identifyDevice('user@example.com');
   ```

That's it! Once the script is live on your site, Vexo starts capturing user sessions, session replays, custom events, and more, just like it does on mobile.
